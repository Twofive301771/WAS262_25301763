# WAS262_25301763
The Github repository for the SF1 in WAS262

The purpose of this repository is to act as a benchmark for the progress on the EcoDash game. 

The purpose of the EcoDash game is to demonstrate how technology can be used across Africa to improve the continent's logistics and infrastructure. Rather than functioning as a regular game, loosely based on Africa, EcoDash must simulate real challenges and scenarios that would occur if one chose to deliver goods across a rural Africa. 

The EcoDash game will be built on HTML Canvas, Javascript and CSS, with no additional libraries, frameworks or game engines.
